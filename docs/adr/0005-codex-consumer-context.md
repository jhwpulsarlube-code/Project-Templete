# Codex 제품 작업은 소비 프로젝트 컨텍스트에서 실행한다

홈 레포에서 사용자 요청을 접수하면 연결 저장소의 작업 트리와 규칙 문서를 확정한다. Codex 제품 작업은 그 작업 트리에서 시작한 세션에서 실행한다. 홈 레포 세션에서 소비 프로젝트의 파일을 읽을 수 있어도, 그 접근만으로는 소비 프로젝트의 규칙·스킬·훅 활성화를 보장할 수 없다.

이 선택은 세션 간에 사용자 요청과 작업 트리 정보를 전달하고, 소비 프로젝트마다 훅의 신뢰 상태를 확인하는 비용을 받는다. 그 대가로 홈 레포를 경유하거나 소비 프로젝트에서 직접 시작할 때 같은 프로젝트 정책을 적용할 수 있다. 필수 차단을 확인할 수 없는 작업은 보류한다.

두 런타임에 각각의 스킬 및 훅 진입점을 배포한다. 공통 스킬 본문과 검사 로직은 한 벌을 공유하고, 프로젝트 정책의 연결은 각 소비 프로젝트가 소유한다.
