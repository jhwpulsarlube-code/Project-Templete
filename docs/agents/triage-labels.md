# 트리아지 라벨

스킬의 다섯 가지 역할을 이 저장소의 실제 라벨에 매핑합니다.

| 역할 | 라벨 | 의미 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 관리자의 평가가 필요함 |
| `needs-info` | `needs-info` | 보고자의 추가 정보를 기다림 |
| `ready-for-agent` | `ready-for-agent` | 명세가 충분하여 자율 에이전트가 작업할 수 있음 |
| `ready-for-human` | `ready-for-human` | 사람이 구현해야 함 |
| `wontfix` | `wontfix` | 처리하지 않기로 함 |

스킬에서 역할을 언급하면 이 표의 해당 라벨을 사용합니다. 실제 라벨 이름이 바뀌면 라벨 열을 수정하세요.
