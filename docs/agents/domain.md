# 도메인 문서

## 탐색 전에 읽을 문서

- 저장소 루트의 `GLOSSARY.md`를 읽습니다.
- 작업 영역과 관련된 `docs/adr/`의 ADR을 읽습니다.

파일이 없으면 조용히 계속 진행합니다. 미리 생성을 요구하지 않습니다. `/domain-modeling`은 용어나 결정이 실제로 정리될 때 필요한 문서를 생성합니다.

## 파일 구성

이 저장소는 단일 컨텍스트를 사용합니다. 용어집은 루트 `GLOSSARY.md`, 아키텍처 결정 기록은 `docs/adr/`에 둡니다.

## 용어집 사용

이슈 제목, 리팩터링 제안, 가설, 테스트 이름 등에서 도메인 개념을 언급할 때 용어집에 정의된 표현을 사용합니다. 용어집에서 피하도록 지정한 동의어를 사용하지 않습니다. 필요한 개념이 없다면 프로젝트에서 쓰지 않는 표현인지 재검토하거나 `/domain-modeling`에서 다룰 공백으로 기록합니다.

## ADR 충돌 표시

결과가 기존 ADR과 충돌한다면 조용히 덮어쓰지 말고 해당 ADR과 충돌 이유를 명시합니다.
