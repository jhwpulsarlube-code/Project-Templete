# 호스트 테스트 규칙

제품·테스트·fake·시임 변경 전에 [공통 절차](../docs/agents/host-test-workflow.md)와
프로젝트 소유 `docs/agents/host-test-project.md`를 읽는다.
제품 범위·안전 경로·variant·타깃 빌드·프로젝트 ADR은 프로젝트 문서가 소유한다.

특성화는 제품 diff 0, 구조 변경은 전처리 동일성 또는 기존 테스트 무수정 통과,
동작 변경은 승인된 결함/ADR 하나와 red 증명, 새 기능은 코드와 테스트를 같은 커밋에 둔다.
ABI 레이아웃 대신 값·레지스터 결과를 단정하고 poison/sentinel로 미변경 상태를 구별한다.
호스트 통과 후 타깃 빌드·ISR·타이밍·산술 폭의 남은 확인을 기록한다.

완료 게이트 정책은 프로젝트 문서의 결정을 따른다. 자동 커밋 검사는 프로젝트 소유
`.githooks/pre-commit.d/`에 둔다. 공통 배포가 프로젝트 보류 결정을 활성화하지 않는다.
