# <호스트 테스트/제품 변경 제목>

설정 시 tracker 메타데이터와 복사될 위치 기준의 실제 링크를 적용한다.
시작: docs/agents/host-test-workflow.md. 관찰표: 티켓 옆 observations.md.

## 범위

제품 파일·영향 함수·안전 경로·전처리기로 선정한 TU/variant·커밋 종류·근거 spec/ADR을 적는다.

## 완료 증거

- [ ] 관찰표의 모든 행을 테스트/대상 증거와 연결했다.
- [ ] 변경 전 측정과 현행/결함 판정을 커밋 종류에 맞춰 수행했다.
- [ ] 선정 구성·안전 경로·양/음성 probe를 확인했다.
- [ ] 비등가를 검출하고 기존 등가 근거·조건부 전제를 현재 입력에서 확인했다.
- [ ] invalid·사라진 키를 검토하고 기준선과 대조했다.
- [ ] 현재 측정과 검토 JSON으로 완료 게이트 종료 코드 0을 확인했다.
- [ ] TU·전체 호스트·필요한 도구/타깃/실기/red 검증이 통과했다.
- [ ] docs/agents/review-host-tests.md로 리뷰했다.

## 실행 기록

명령·HEAD/변경분·범위·구성·CPU 예산·경과시간·측정/분류/검토 증거 경로·결과를 적는다.

## 대상 확인

실기 절차·합격 기준·담당자·결과를 적는다. 미완료는 tracker의 사람 확인 상태로 남긴다.

완료 게이트·검토 JSON·stamp 항목은 프로젝트 소유 `docs/agents/host-test-project.md`의 적용 정책을 따른다. 보류 시 해당 ADR의 대체 완료 증거를 기록한다.
