# 호스트 테스트 리뷰

제품·호스트 테스트·fake·시임·변이 도구 리뷰에서 읽는다.
규칙 축은 test/AGENTS.md와 host-test-workflow.md, 명세 축은 해당 spec/ADR이다.
Matt code-review를 사용하면 각 축에 규칙/명세·관찰표·게이트 결과를 전달한다.

- 전처리기로 선정한 TU/variant·함수·안전 경로와 관찰표가 일치한다.
- 비기본 입력·경계·이전 상태·fake 인자·후속 결과를 단정하고 변이로 반증했다.
- 도달 가능한 비등가는 검출됐고 관찰 부족을 제외로 처리하지 않았다.
- 등가 근거와 조건부 전제/깨지는 조건을 현재 생산자·상수·헤더·variant에 대조했다.
- 현재 입력의 완료 게이트가 통과했고 probe·invalid·사라진 키를 검토했다.
- 커밋 종류·무접촉·red·타깃 증거가 규칙과 일치한다.

완료: 모든 항목의 증거를 확인했다. 발견 사항은 파일·키·규칙·부족한 증거를 함께 기록한다.
생존자 수 자체를 결함으로 판단하지 않는다. 현재 전제 미확인은 완료 차단 사항이다.

완료 게이트·검토 JSON·stamp 항목은 프로젝트 소유 `docs/agents/host-test-project.md`의 적용 정책을 따른다. 보류 시 해당 ADR의 대체 완료 증거를 기록한다.
