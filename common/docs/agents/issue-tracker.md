# 이슈 추적기

프로젝트 소유 `docs/agents/workflow-project.md`에서 추적기와 저장소를 확인한다.
GitHub Issues면 `gh issue view <번호> --comments`로 조회한다. 로컬 Markdown이면
`.scratch/<feature>/issues/<NN>-<slug>.md`의 Status와 Comments를 읽는다.
트리아지 역할은 [라벨 안내](triage-labels.md)를 따른다.
호스트 테스트 티켓은 [템플릿](templates/host-test-ticket.md)과 [공통 절차](host-test-workflow.md)를 따른다.
